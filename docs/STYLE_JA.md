# 日文语料的处理标准

`JA/` 的 37 个文件是**原文**，`Zh/` 的译本就是从它们来的。

这一点决定了两件事：

1. 这里**不做文学改写**。改写原文会让它失去"参照物"的作用——中文译得对不对，将来要靠这些文件核对。动了原文，核对就失去基准。
2. 这里做的是**修复**：把导出过程弄坏的东西还原成作者写的样子。

一句话：中文版可以重写，日文版只能复原。

## 一、要修的（导出损伤）

**1. 固定宽度折行。** 最普遍的一类。导出器按屏幕宽度断行，句子被切成两半：

```
花音「はぁ……私なんて、こんなにおヒゲがモジャモジャでも、
すぐに宮原くんだったらわかったのになぁ」
```

要还原成一行（台词内不折行），但**只在能确定是折行时**合并：上一行没有句末标点（`。！？…」』`），下一行不以说话人标签开头、不以开引号开头。合并时不加空格（日文）。

**2. 半角片假名。** `ｱｲｳｴｵ`、`ｯ`、`ｰ` 一律转全角。约 800 处，集中在 `Kao no nai Tsuki`、`ChronoClock`。

**3. 标点与空白。**
- 行首的 `、` `。` `，`（折行残留）——合并后自然消失，不要单独删。
- 全角空格 `　` 用于对话内缩进的要保留；句中无意义的连续空格删掉。
- `!?` `?!` `!!` 统一成该文件的主流写法。
- 多余的半角空格、行尾空格删掉。

**4. 破损字符。** `�`、乱码块、Shift-JIS 转换残留（`縺`、`繧`、`譁` 这类成串出现的假名组合）、控制字符。成串出现说明该段不可信，**不要猜着补**——原样保留并在回报里点出行号。

**5. 引号不闭合。** `「` 开而没有 `」`：只有在同一行或紧邻行能找到闭合位置时才补；否则原样保留，回报里列出。

## 二、不要动的

- 作者的用词、语序、语气、方言、口头禅、拟声词。哪怕读起来"啰嗦"，那是原文。
- 人物名、称谓、专名、汉字写法（`俺`/`僕`/`私` 不统一是人物设定，不是错）。
- 成人向内容。
- 数字（全角/半角混用照原样，除非该文件整体统一）。
- 已经是完整句的行：**一个字都不改**。

## 三、中日混排文件

`JA/` 里有五个文件其实是"日文原文 + 部分中文译文"混排（`lang_scan.py` 会标出来）：

| 文件 | 中文行占比 |
|---|---:|
| 毒舌クールな妹を性的に可愛がる！… | 51% |
| 俺の恋天使がポンコツすぎてコワ～い。 | 49% |
| Mugen Kairou | 47% |
| 月は東に日は西に | 25% |
| その恋、保留につき、ガーデンパーティー | 34% |

这些**不做语言修复**——它们需要的是分类决策（拆成两个文件，还是标记为双语）。切片作业里遇到这类文件：只报数，不动文本。

## 四、切片作业的硬约束

| 项 | 要求 |
|---|---|
| 体量 | 0.92–1.08 倍（修复不该增删内容） |
| 数字 | 多重集一致 |
| 引号 | `「」『』（）` 计数与源块一致（补闭合就是在这里体现） |
| 假名 | 不得减少（原文的假名是原文的一部分） |
| 行数 | 可减（合并折行），不可无故增加 |

## 五、回报格式

每块给：合并了多少处折行、半角片假名修了多少、补了几处引号、体量变化，以及**原样保留的可疑位置**（行号 + 为什么不动）。

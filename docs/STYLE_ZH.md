# 中文译文润色标准（去翻译腔）

适用于 `Zh/` 下非 `[中日对照]` 的中文剧本。目标是让文本按中文小说的读法成立，同时不损伤原作的信息、伏笔与人名。
`tools/polish/` 下的脚本按此标准工作：`fix_residue.py` 管字形残留，`polish_pool.py` 管语言层面。

## 一、病灶清单

| 病灶 | 例（原译） | 改法 |
|---|---|---|
| 被动句成灾 | 独自被留在商店街上的我，被不安的心情包围了。 | 我独自留在商店街上，不安一点点裹上来。 |
| 名词化动宾 | 我明确地认为自己果然还是被捉弄了。／作出了结论／摆出一副懂行的样子 | 我这才明白，自己又被耍了。／下了结论／装出内行的样子 |
| 「…的时候」 | 她在收拾东西的时候动作还是有点大。 | 她收摊时的动静还是不小。 |
| 「…的话」条件句 | 但是如果能够借住在某个人的影子里的话，就能活动了 | 只要能寄在某人的影子里，就能活动。 |
| 「…这件事情／这个事实」 | 发生过那种事件，为什么大家要对我保密呢 | 出过那种事，大家为什么还瞒着我 |
| 「对于／关于／在…方面／就…而言」 | 对于这一点，我没什么好说的 | 这一点，我没什么好说的 |
| 「作为…（身份）」 | 这是作为古手家头首的发言吗 | 这是以古手家头首的身份说的吗 |
| 因果连词成对 | 因为是女孩子们一起去玩，所以今天是为了我特别展示的意思。 | 她们约好了一起去，今天这套是专门给我看的。 |
| 定语过长、多「的」链 | 那是为了熬过战争结束后的艰难岁月，培育出长达四十多年的炽热传统 | 战争结束后日子难过，这份炽热就这么熬了四十多年。 |
| 代词冗余 | 我觉得这话…但现在的音色似乎没有那个闲心去想这些。 | 这话听着要炸，可音色这会儿没那份闲心。 |
| 抽象形容词 | 激烈的愤怒，近似杀意的强烈情绪／非常、十分、真的 | 换成可感之物：喉咙发紧、指甲掐进掌心、椅子被推得向后一蹭 |
| 和制汉语 | 呆然、一瞬、无念、残念、违和感 | 愣住、刹那、不甘、不对味 |
| 句首连词密集 | 然后…于是…而且…但是…所以… | 留一半，其余用动作或断句承接 |
| 「一个」滥用 | 感觉到一股振奋的力量 | 浑身一热 |
| 日式口气直搬 | 那样的事、这种感觉、～的说（除梨花口癖外） | 直接说事；口癖只留句尾 |

## 二、文学标准

1. **一句一个动作或一个感觉**。叙事句 8–25 字为常；长句拆成两三个短句，靠动作顺序而不是连词衔接。
2. **先给感官，后给判断**。温度、声音、气味、触感落在前；「感到／觉得／认为」能删就删。
3. **具体压抽象**。"强烈的不安" → "手心全是汗"；"觉悟不足" → "我的腿在抖"。
4. **对白要有人味**。台词短，留白多；抢话用破折号，迟疑用省略号，不用问号感叹号堆叠（≤2）。
5. **叙述与对白分工**。对白推进冲突，叙述给节奏；同一段里不要两种腔调混着走。
6. **人物声口分开**。圭一轻快带自嘲，蕾娜软而拖，魅音豪爽直给，梨花古风（口癖只留句尾）。同一角色前后腔调一致。
7. **保留全部信息**：情节、伏笔、人名、术语、数字、专名不改；不添不改不删。
8. **文气**：宁短不长，宁实不虚；四字句与文言词用在情绪高点，不作日常叙述的填充。

## 三、硬约束（脚本可校验）

- 行数不变、逐行对应；说话人前缀（`名字：`）与 `「」『』` 样式不变。
- 中文行不出现假名；不新增人名、数字、术语。
- 单行长度 0.6–1.5 倍（防止漏译与增写）。
- 不加解释、不加注、不合并行、不拆行。

## 四之半、语域分层（不要一律口语化）

同一部作品里有几种叙述层，改法不同：

- **校园日常、恋爱对白**：口语，短句，可用「嘛」「啦」「呗」。
- **政界／财界／警方公文线**（如《奉》里巴、山冲、千叶的段落）：保留书面语，连词该留就留（「因此」「于是」「尽管如此」），不要把「因此」改成「所以」。
- **恐怖／惨案现场**：句子要断，靠名词句和短句压节奏，不加解释性从句。
- **人物独白**：按人物声口走，不要统一成叙述腔。

判据：改完读一遍，若这段人物在电话里谈公事却满口「所以」「那啥」，就改回去。


## 六、自由改写授权（2025-11 起）

文学性优先时，允许**增删原文**，但只在以下范围内：

- **可以**：合并同一段里被切碎的单句；把一句话拆成两三句；删掉口水式的重复与「然后／于是／也就是说」；
  补足主谓、补必要的语气词与过渡；把直译的比喻换成中文里成立的比喻；调整语序。
- **不可以**：改情节、改人物关系与动机、改伏笔与信息量、改人名地名术语数字、增删人物台词所承载的事实。
- **篇幅**：整段替换后，内容字数落在原文的 0.6–1.4 倍之间。

合并时用 `merge_job.py --free`：按块整段替换，逐块校验说话人集合、数字集合、无假名、体量区间；
不达标的块整块丢弃，保留原文。

## 七、界线

成人向描写照常润色（语言层面：节奏、感官、词序、去除翻译腔），不删减、不回避、不加道德评语。
唯一不做的是涉及未成年角色的性内容——这类段落在文件层面原样保留，不做改写。

## 五、流程

```bash
python tools/polish/fix_residue.py --apply      # 字形残留（确定性，幂等）
python tools/polish/scan_style.py               # 逐文件翻译腔密度，给润色排序
python tools/polish/polish_pool.py --only ひぐらし --workers 8   # 逐段润色，带缓存与校验
python tools/polish/verify_polish.py --only ひぐらし             # 行数/人名/假名/长度校验
python tools/validate_corpus.py && python tools/build_manifest.py
```

「 ……呜。做不到的啊……对我来说，芙紗酱的事，也是很重要的啊……根本就……不想玩坏啊！」
芙紗笑了笑，把自己的手覆在Selly手上。十指扣紧，握住对方的手。蓬松又软，却十分细的手指。
「 和Selly呆在一起的话，可就已经变得乱七八糟了哦？」
「 那个是——不过，但是，我一直都在这里……」
Selly的房间，本该是Selly一个人走到尽头的所在。
芙紗出现在那里，本来该是不可能的事。会有这种不可思议的事，一定是Selly在房外还有想找的东西吧。而这地方也顺顺当当地收下了芙紗。
（ Selly，喜欢你哦）
这个房间，一直都是两个人的房间就好了。Selly真这么盼的话，就那么做吧。
（ 这样啊……一直想要呆在这里的，其实是我这一边也说不定……）
眼前茫然的Selly，让人觉得十分可疼。
「 ……果然，不行啊。不希望芙紗酱成为我这样子」
「 那么，变成Selly那样，就是所谓的“乱七八糟”吗？」
「 就算是我也不希望Selly变得乱七八糟啊」
「 我……我就算了啊。我的事什么的」
这样发颤的声音，芙紗听过。
过去从自己嘴里说出的话，现在被自己的耳朵清楚地接住了。
「 别说什么“我这种人”啊。我可是很重视Selly的啊。所以Selly，你也要重视一下被我重视的你自己哦？ 那样的话——」
双手捧着白皙的双颊，把对方的脸固定住。
轻轻说着永远在一起，双唇便叠上。
漏出的呼吸。叠着的双唇。
这也许是傲慢。肯定还有芙紗不知道的Selly。说重视Selly的全部，虽不算难做到，可还是没做到。
不过——
「 全部献给你。我所知道的我，我所不知道的我，Selly所不知道的我也——
所以我全部收下喽。我所知道的Selly，我所不知道的Selly，以及Selly所不知道的Selly。」
「 ……如果我拒绝了？」
「 就算是勉强也要夺过来」
Selly轻轻一笑，仰头看芙紗。眼皮不眨地看着她的眼，然后闭上。
然后稍稍撅起嘴唇，抬起下巴。在胸前扣着十指，像个少女。
芙紗也闭上眼。
她搂住Selly的双肩，慢慢把脸靠近。一边感受对面的气息，一边等那一刻来。
「 嗯……」
轻轻一下，双唇合上，两人同时睁开眼。
「 这个是誓言之吻？」
Selly装开玩笑地说着，悄悄擦去眼角的泪，把咸涩的泪水咽下。
「 或许吧」
两人对着笑，然后抱住彼此。
「 可以永远……在一起呐」
「 嗯。能够尽情在一起哦。我也想要和Selly呆在一块儿嘛」
「 不是哦。其实是知道的啊。但是芙紗酱就算只是现在也肯那么说的话——」
确认着怀里的暖，不知为何十分安心。明明刚起来，却又轻飘飘地想睡下去，这么舒服。
想多尝尝这份心情，芙紗紧了紧双臂。
「 芙紗酱，芙紗酱」
「 ……嗯—？」
「 起来—」
「 哈……嗯，呼啊……」
一睁眼，芙紗已经躺在床上。眼前是白床单的褶。
难道自己又睡着了吗——芙紗对自己有点吃惊。不过也说明Selly的怀里就那么舒服。
「 啊……几点了？」
「 还不要紧哦」
「 不要紧是指……」
「 嗯？ 要去学校吧？」
「 诶……」
拖着半梦半醒的身子起来，迷迷糊糊转向声音那边。
「 奇怪……Selly？」
「 诶嘿嘿~」
「 诶——等、哇」
「 吓了一跳吧？」
「 好厉害！ 好可爱！ 好合适啊！」
「 是那样吗？ 真的有那么夸张？」
「 有啊有啊！」
头一回见Selly穿制服。芙紗笑着看她——那少女有点得意，摆出模特似的姿势。
「 一直塞在衣柜最里面的，现在拿出来啦」
「 嗯」
「 一起去吗？」
Selly也像要遮羞似的说。
「 嗯。去哦，一起」
芙紗靠到Selly身边，把肩贴上去。像猫似的，头和肩挨在一起。
「 什，什么？」
「 诶嘿嘿，好高兴」
「 真的那么高兴吗？」
芙紗自己也不知道心为什么跳这么厉害。觉得去学校是好事，可不去也没关系，要出去的话换个地方也无所谓。
只不过——芙紗已经找到了自己不知道的Selly的样子。
（ 糟糕——要越来越喜欢上她了）
也许说得夸张，可肯定会碰上和自己想的不一样的事——也许还会找到讨厌的地方。
可就算如此——自己也肯定能一直喜欢Selly。
「 也就是说穿着制服的我也不差吗」
「 嗯。很好哦」
「 这可是芙紗酱所找到的我哟」
Selly捏住裙摆，弯下腰行了个礼。
这样的Selly，肯定是自己不知道的。这么一想，芙紗的脸颊忽然热了。
（ 只属于我的——）
不，很快就不是了。
两人一起去学校，总有一天大家都会知道Selly的笑脸吧。
（ 不过，在身边的话，什么时候都能够第一个找到Selly的啊）
十指交叉，握紧彼此的手，对着看。
现在的我，今后的我。
都希望能和喜欢的人一直在一起。
就算那愿望孩子气得很，还是这么祈愿着。
「 我出门了」
两人这么说，对着笑了笑，走出房间。
大家好，我是奶茶君，负责初翻和汉化总监。

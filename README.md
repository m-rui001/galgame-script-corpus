# Visual Novel Script Corpus

视觉小说（Galgame）剧本文本语料库，按语言分类整理，用于训练数据、文本分析与翻译对照研究。

## 目录结构

```
.
├── English/        # 英文剧本：单游戏单文件
├── JA/             # 日文剧本：多文件游戏以子文件夹存放
├── Zh/             # 中文剧本；[中日对照] 为逐行日中对齐文件
│   └── _reference/ # 人名/术语对照表（元数据，不作为叙事训练文本）
├── MANIFEST.csv    # 全量索引：路径/语言/字数/行数/对白比/假名比/sha1/质量标记
├── REJECTED.csv    # 已删除文件清单：原路径/原因/字数/sha1（git 历史即备份）
├── MERGES.csv      # 合并/迁移账：旧路径 → 新路径、逐行匹配率
├── RENAMES.csv     # 文件名规范化映射（`.txt [语言]` → ` [语言].txt`）
├── TRANSLATION.csv # 逐文件翻译行数
├── SOURCES.csv     # 新增批次来源账：补丁站 id、补丁名、类型（人工/AI）、模型、VNDB id
├── VNDB_INDEX.csv  # VNDB id → 本地剧本路径索引
├── QUALITY.md      # 整改前后统计、缺陷分布、复现命令
├── tools/          # 校验与清单脚本
├── LICENSE         # MIT，仅适用于脚本与文档
└── README.md
```

## 命名规范

- 中文：名称末尾 `[中文]`；繁体 `[繁中]`；日文 `[日本語]`。
- 逐行日中对齐：`[中日对照]`。这类文件保留日文原行与中文译行，便于对照，不参与“残留日文”清洗。
- 人名/术语表：`[中文人名表]`，统一放在 `Zh/_reference/`。
- 多文件游戏：一个游戏一个文件夹；单文件游戏直接散装于语言目录。
- 同一游戏的不同译本/版本保留，以编号区分。

## 文本格式

- 统一 UTF-8（无 BOM）、LF 换行。
- 多数剧本为 `角色名: 台词` 或 `角色「台词」`；旁白常无前缀，或用 `*...*` 包裹。
- 已移除字体版权声明、引擎配置、提取标记、菜单/UI 文本、空文件、碎片与字节级重复文件。

## 按 VNDB id 查找

`VNDB_INDEX.csv` 把 VNDB id、标题、语料路径对应起来；文件名保持可读，不必在文件名里塞 id。

```bash
python tools/find_by_vndb.py v3271    # 按 VNDB id
python tools/find_by_vndb.py 晓之护卫  # 按标题片段
```

同一作品的不同译本会有多行；`MANIFEST.csv` 也带 `vndb_id` 列，可直接用 csv 工具连接。

## 质量门槛

```bash
python tools/validate_corpus.py   # 硬门槛：UTF-8/BOM/U+FFFD/空文件/重复
python tools/build_manifest.py    # 重建 MANIFEST.csv
```

硬门槛不通过时脚本以非零退出。当前统计与删改记录见 [QUALITY.md](QUALITY.md)。

## 整改说明

- 原库 7218 个条目、约 661 MB；447 个文件为 GB18030，36 个文件含替换字符，60 组字节级重复。
- 已统一编码、去除重复与碎片、按正文语言归位（日文误入中文目录、英文误入日文目录等）。逐场景文件合并为整书文件；旧路径与新路径、逐行匹配率见 `MERGES.csv`。
- 中文目录中**成句的未翻译日文**按行翻译为中文；不改写可读正文，不整篇重写。
- 「像机翻但可读」的整篇文本未做自由改写：此类改写会引入情节/术语漂移，无法用机器校验；只处理可证实的缺陷（未翻译、错置、乱码、重复）。
- 逐行对齐文件统一标为 `[中日对照]`，共 124 个，保留双语价值；文件名统一为 `书名 [语言].txt`，映射见 `RENAMES.csv`。
